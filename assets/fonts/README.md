# Polices d'icônes embarquées

| Fichier | Famille | Rôle (THEME.md § 2) | Licence |
|---|---|---|---|
| `SymbolsNerdFontMono-Regular.ttf` | Symbols Nerd Font Mono | modules dont le texte est l'icône (espaces de travail, volume, power) | MIT (`LICENSE-NerdFonts`) |
| `HackNerdFont-Regular.ttf` | Hack Nerd Font | icônes collées à du texte (horloge, CPU, mémoire, GPU, réseau, mises à jour) : police de repli réellement utilisée par Waybar, avance de 15,65 px à 26 px (Symbols Nerd Font a le même dessin mais une avance plus large) | MIT + Bitstream Vera (`LICENSE-HackNerdFont.md`) |
| `FontAwesome7Free-Regular-400.otf` | Font Awesome 7 Free (Regular) | calendrier de l'horloge | SIL OFL 1.1 (`LICENSE-FontAwesome7.txt`) |
| `FontAwesome7Brands-Regular-400.otf` | Font Awesome 7 Brands | logo Spotify (mpris) | SIL OFL 1.1 (`LICENSE-FontAwesome7.txt`) |
| `FontAwesome4-Regular.ttf` | FontAwesome | pause (mpris) | SIL OFL 1.1 (`LICENSE-FontAwesome4.txt`) |

Installées dans `~/.local/share/fonts` par `install.sh` (phase 11), sur toutes les distributions.
